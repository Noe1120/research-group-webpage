# 科研组官网

南京邮电大学计算机、软件、网络空间安全学院科协技术部门科研组静态官网。

项目采用原生 HTML、CSS 和 JavaScript 开发，不需要构建工具或后端服务，可直接部署到 GitHub Pages。当前正式站点由首页、关于、成员、研究方向和招新五个页面组成。

## 当前站点结构

```text
webpage/
├─ index.html                         首页
├─ about.html                         关于科研组
├─ members.html                       成员介绍
├─ research.html                      研究方向
├─ join.html                          秋季招新
├─ styles.css                         全站基础样式
├─ multipage.css                      多页面和专题样式
├─ site.js                            全站交互脚本
├─ assets/images/                     官网正式图片
├─ anime-character-showcase/          MOMO-01 独立角色展示
├─ character-birthday/                首页人物试映页
├─ character-blue-showcase/           研究方向人物试映页
├─ character-cutout/                  关于页人物试映页
├─ character-ginkgo-showcase/         成员页人物试映页
├─ character-lavender-showcase/       招新页人物试映页
├─ character-concepts/                早期 CSS 角色方案
└─ README.md                          项目说明
```

独立角色展示目录没有加入官网导航，不影响正式站点。它们用于保存早期方案和人物排版效果，可通过各自目录下的 `index.html` 单独查看。

## 正式站点文件

| 文件 | 负责内容 |
| --- | --- |
| `index.html` | 官网首页。包含主视觉、四个主页面入口、实验室通知列表和招新宣传区。 |
| `about.html` | 科研组介绍。说明团队定位、研究过程和工作方式，并展示关于页人物。 |

| `research.html` | 研究方向页面。展示生成式 AI、网络空间安全、软件与系统三个方向，以及从论文到项目的研究流程。 |

| `README.md` | 项目结构、修改记录、维护方式和部署说明。 |

## 本地预览

不要直接依赖双击 HTML 进行完整测试。建议在项目目录启动静态服务器：

```bash
python -m http.server 4173
```

Windows 环境如果 `python` 命令不可用，也可以尝试：

```bash
py -m http.server 4173
```

然后访问：

```text
http://localhost:4173/index.html
```

项目图片均为本地资源。联网主要用于加载 Google Fonts；网络不可用时浏览器会使用后备字体，页面主体和人物图片仍可显示。

## GitHub Pages 部署

1. 将 `webpage` 目录中的全部文件和子目录上传到 GitHub 仓库。
2. 打开仓库的 `Settings` → `Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择默认分支，目录选择 `/ (root)`，然后保存。
5. 等待 GitHub Pages 完成部署后，通过仓库提供的网址访问。

后续修改时，重新上传发生变化的 HTML、CSS、JavaScript 或图片文件即可。必须保持当前相对目录结构，否则页面中的样式、脚本和人物图片路径会失效。

## 维护说明

- 修改页面文字：编辑对应的 `.html` 文件。
- 修改全站基础颜色、按钮、页头或页脚：优先编辑 `styles.css`。
- 修改人物舞台、页面卡片、公告栏、花瓣或银杏叶：编辑 `multipage.css`。
- 修改主题切换、移动导航或飘落动画：编辑 `site.js`。
- 替换人物图片：替换 `assets/images/` 中对应文件，并保持文件名不变。
- 新增正式页面时，需要同步更新五个正式页面的顶部导航，并在 README 中登记。
- 独立角色预览目录不属于正式导航；删除前应确认不再需要方案存档。
